# Security Policy

BSJ-MM-SEC-0 is a security research project maintained by
MohammadArshiya Rahgozar (@marshiyar) and Mobin Norouzi.

## Supported Versions

This project has no releases yet. Only the latest code on the `main`
branch is supported.

## Reporting a Vulnerability

Please do **not** open a public issue, pull request, or discussion for
security problems.

Report privately through GitHub instead:
1. Go to the **Security** tab of this repository.
2. Click **Report a vulnerability**.
3. Describe the issue, how to reproduce it, and its impact.

What to expect:
- We acknowledge reports within 7 days.
- We send status updates at least every 14 days until it is resolved.
- If we accept the report, we fix it and credit you (unless you prefer
  to stay anonymous). If we decline it, we explain why.

## Scope

This policy covers the code and workflows in this repository. Findings
about third-party software we research should go to that project's own
maintainers through their disclosure process.

## Safe Harbor

We will not take action against anyone who reports in good faith,
avoids harming users or data, and gives us reasonable time to fix the
issue before sharing it publicly.
